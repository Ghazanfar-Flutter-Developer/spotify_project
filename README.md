# 🎵 Spotify Clone

> **Spotify-inspired Flutter music application with Cloud Firestore integration and in-app audio playback.**

Spotify Clone is a Flutter-based music application inspired by modern music streaming platforms.

The application uses **Cloud Firestore** to store and retrieve music data and provides in-app audio playback with basic player controls such as play and pause.

This project was built to practice Flutter UI development, Firebase integration, cloud data handling, and audio playback.

---

## ✨ Features

### 🎵 Music Library

- Browse available music within the application
- Music data retrieved from Cloud Firestore
- Display music information in a modern music-app interface

### ▶️ Audio Playback

- Play music directly inside the application
- Pause currently playing music
- Control music playback from the player interface

### ☁️ Cloud Firestore

- Store music-related data in Firestore
- Retrieve music data dynamically
- Connect the Flutter application with Firebase

### 📱 User Interface

- Spotify-inspired design
- Music browsing interface
- Player interface
- Smooth navigation between application sections
